Horror Movie Database

A full-stack movie catalog for horror fans to discover films, organize a watchlist, and share ratings and reviews.

View Source on GitHub →

Project Overview

Horror Movie Database combines a searchable film catalog with personal features for tracking movies. Visitors can explore film details and filter the collection, while signed-in users can maintain watchlists and contribute ratings and reviews.

Key Features

Search & Discovery

Search by title or plot, filter by subgenre and credits, and sort movie results.

Movie Information

Explore release date, runtime, director, cast, production companies, plot, and subgenres.

Watchlist

Registered users can save films, update watched status, and manage a personal watchlist.

Ratings & Reviews

Users can rate films and write reviews, with review listings available for each movie.

Technology & Structure

The frontend uses React 18, React Router, Axios, and Context API. The Node.js and Express backend exposes API routes backed by MySQL. The application also uses JWT authentication, bcrypt password hashing, and request rate limiting.

Movie discovery and detail import can use The Movie Database (TMDb) API.
