Financial Tracker

A full-stack personal finance planner for organizing income, expenses, savings, and debt payoff progress.

View Source on GitHub →

Project Overview

Financial Tracker brings everyday money management into one application. Users can record transactions, monitor financial totals, and keep debt balances and payment details organized.

Key Features

Financial Summary

A dashboard summarizes income, expenses, remaining debt, and net savings.

Transaction History

Record income and expenses by category, review history, and edit or delete entries.

Debt Tracking

Organize creditors, balances, minimum payments, and interest rates.

Account Access

JWT-based authentication supports sign-in and protected account workflows.

Technology & Structure

The frontend uses React, TypeScript, and Vite, with React Router for navigation and Axios for API requests. The FastAPI backend uses Pydantic schemas, ORM models, and a SQL database. Shared frontend styles keep cards, tables, and forms visually consistent.
