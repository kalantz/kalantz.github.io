CYBERSECURITY LAB 10

Security Onion

Deploying network monitoring and investigating controlled activity with Security Onion.

Lab Overview

Security Onion 3.3.0 was deployed in standalone mode with separate management and monitoring interfaces. Controlled reconnaissance, vulnerability scanning, and credential activity were generated in the isolated lab and investigated using Zeek telemetry, Suricata alerts, packet capture, and the SOC interface.

Areas of Focus

  • Zeek network telemetry and packet visibility
  • Suricata intrusion alerts for controlled test activity
  • SOC investigation and correlation of network events
