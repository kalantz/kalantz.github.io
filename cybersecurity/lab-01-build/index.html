CYBERSECURITY LAB 01

Building the Lab

Creating and validating an isolated virtual environment for hands-on cybersecurity exercises.

Lab Overview

This lab established a reproducible cybersecurity home lab in Oracle VirtualBox. Attacker, server, workstation, and intentionally vulnerable systems were connected through an isolated Host-Only network for controlled security testing.

Areas of Focus

  • Virtual machine and network configuration
  • Host-Only network isolation
  • Connectivity validation between lab systems
