CYBERSECURITY LAB 09

Wazuh SIEM

Centralizing Windows and Linux endpoint telemetry with Wazuh SIEM.

Lab Overview

Wazuh was deployed as a centralized SIEM and connected to Windows and Linux agents in the isolated lab. After establishing a telemetry baseline, the investigation reviewed file-integrity monitoring, authentication failures, process activity, and PowerShell-related events.

Areas of Focus

  • Wazuh agents on Windows and Linux endpoints
  • Baseline telemetry and endpoint event investigation
  • File-integrity, authentication, process, and PowerShell monitoring
