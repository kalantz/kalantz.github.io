CYBERSECURITY LAB 06

Password Attacks

Comparing controlled online password auditing with offline password-hash cracking.

Lab Overview

The lab evaluated Ncrack and Medusa for online authentication testing and John the Ripper for offline hash cracking, using designated systems in the isolated home lab. It also documented compatibility issues encountered when testing legacy authentication services.

Areas of Focus

  • Online SSH password auditing with Ncrack
  • Offline password-hash analysis with John the Ripper
  • Tool compatibility and verification of recovered credentials
