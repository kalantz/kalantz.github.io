CYBERSECURITY LAB 15

Active Directory Attacks

Evaluating Active Directory attack paths in the isolated home.lab domain.

Lab Overview

Building on the domain established in Lab 14, this exercise simulated common Active Directory attack techniques from an isolated Kali system against the Windows Server 2022 domain controller. Windows authentication events were also reviewed to corroborate selected activity.

Areas of Focus

  • SMB and LDAP enumeration and controlled password spraying
  • Kerberos service-principal enumeration and Kerberoasting
  • Offline password recovery and Windows event review
