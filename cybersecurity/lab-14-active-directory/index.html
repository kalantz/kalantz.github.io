CYBERSECURITY LAB 14

Active Directory

Organizing and validating the existing Windows Server 2022 home.lab directory environment.

Lab Overview

This lab examined the existing Windows Server 2022 domain controller for the home.lab domain, then organized and extended the environment as a foundation for later attack and defense exercises. It did not create a second domain.

Areas of Focus

  • Domain-controller, DNS, and Active Directory validation
  • Organizational-unit, user, and group organization
  • OU deletion protection and domain security settings
