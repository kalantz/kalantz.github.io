CYBERSECURITY LAB 13

Incident Response

Investigating simulated network activity through triage, packet evidence, and corroborated findings.

Lab Overview

In the isolated home lab, a simulated Kali host generated reconnaissance and credential-based activity against Metasploitable 2. Security Onion telemetry and packet captures were used to determine which actions occurred, which succeeded, and what the evidence could support.

Areas of Focus

  • Initial triage using Security Onion alerts and network context
  • Packet-capture review to corroborate reported activity
  • Separating confirmed outcomes from unsuccessful attempts
