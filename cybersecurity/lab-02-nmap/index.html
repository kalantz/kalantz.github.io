Network Discovery with Nmap

Performing network reconnaissance to discover hosts, enumerate services, identify operating systems, and assess exposed vulnerabilities.

Overview

Building on the isolated environment created in Lab 01, this lab focused on network reconnaissance using Nmap. The objective was to identify live systems, enumerate exposed services, fingerprint the target operating system, and identify potential vulnerabilities.

No exploitation was performed during this lab. The focus remained on reconnaissance and analysis, establishing an understanding of the target's attack surface before any offensive activity.

Objectives

  • Discover live hosts on the isolated network.
  • Perform TCP and UDP port scans.
  • Identify service versions.
  • Fingerprint the target operating system.
  • Use Nmap NSE scripts for additional enumeration.
  • Identify publicly documented vulnerabilities.
  • Analyze findings from an attacker's perspective.

Lab Environment

Attacker

Kali Linux security workstation at 192.168.56.40.

Target

Metasploitable 2 at 192.168.56.50.

Network

Isolated VirtualBox Host-Only network using the 192.168.56.0/24 subnet.

Tool

Nmap 7.99 running on Kali GNU/Linux 2026.2.

Reconnaissance Process

The reconnaissance process progressed from broad network discovery toward increasingly detailed analysis of the target system.

01 — Host Discovery

Identified active systems on the isolated network using an Nmap ping sweep.

02 — Port Enumeration

Identified open TCP and UDP ports exposed by the target.

03 — Service Identification

Determined software and service versions running on exposed ports.

04 — OS Fingerprinting

Used Nmap OS detection to identify the underlying operating system.

05 — NSE Enumeration

Used default Nmap scripts to collect additional information about exposed services.

06 — Vulnerability Enumeration

Used Nmap vulnerability scripts to identify potentially vulnerable services and configurations.

Results

The reconnaissance process successfully identified the intended target, exposed services, operating system, service versions, and numerous publicly documented vulnerabilities.

Network Visibility

Active systems and VirtualBox network infrastructure were identified through host discovery.

Attack Surface

TCP and UDP enumeration revealed numerous exposed services on the intentionally vulnerable target.

Service Intelligence

Version detection and NSE scripts provided detailed information about exposed software and configurations.

Vulnerability Intelligence

Multiple publicly documented weaknesses were identified for later validation and controlled exploitation.

Lessons Learned

  • Enumeration should precede exploitation.
  • Different Nmap scan types provide different levels of visibility and speed.
  • Service version detection significantly increases reconnaissance value.
  • NSE scripts can rapidly enrich reconnaissance results.
  • Vulnerability scan results require validation before treating them as confirmed vulnerabilities.
