CYBERSECURITY LAB 17

Azure Fundamentals

Building a security-focused Azure foundation for cloud monitoring and Sentinel.

Lab Overview

This lab established a security-focused Azure environment using network segmentation, storage controls, Key Vault, managed identities, RBAC, and diagnostic logging. Planned Ubuntu VM provisioning was blocked by the subscription's allowed-SKU policy, so no live VM workload was added.

Areas of Focus

  • Virtual networks, subnet association, and network security groups
  • Storage access, Key Vault, managed identities, and RBAC
  • Activity and diagnostic logging for later Sentinel investigation
