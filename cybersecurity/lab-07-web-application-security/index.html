CYBERSECURITY LAB 07

Web Application Security

Testing common web application weaknesses against intentionally vulnerable lab applications.

Lab Overview

Against DVWA and Mutillidae on the isolated Metasploitable 2 system, the lab examined web-service discovery, SQL injection, cross-site scripting, local file inclusion, path traversal, and authentication and session behavior.

Areas of Focus

  • Burp Suite and Gobuster for request inspection and discovery
  • SQL injection, XSS, LFI, and path-traversal testing
  • Authentication, session handling, and client-controlled state
