CYBERSECURITY LAB 16

Active Directory Defense

Hardening Active Directory and re-testing selected attack paths in home.lab.

Lab Overview

This lab is the defensive counterpart to Lab 15. It applied security controls to the existing home.lab domain, verified configuration from both the domain controller and attacker perspective, and re-tested selected techniques to assess the changes.

Areas of Focus

  • Password and account-lockout policy hardening
  • Service-account credentials, Kerberos encryption, and delegation scope
  • Re-testing attack paths and reviewing resulting evidence
