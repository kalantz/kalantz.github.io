CYBERSECURITY LAB 08

Windows Logging

Using Windows audit events and PowerShell logs to trace and correlate host activity.

Lab Overview

On the isolated Windows 11 client, the lab configured and reviewed security and PowerShell logging, then correlated authentication, account-discovery, and process activity. Script Block Logging (Event ID 4104) and process creation auditing (Event ID 4688) provided additional investigation context.

Areas of Focus

  • Successful and failed logons and account-related events
  • PowerShell Script Block Logging (Event ID 4104)
  • Process creation auditing (Event ID 4688) and event correlation
